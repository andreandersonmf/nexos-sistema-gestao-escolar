# Nexo's - Sistema de Gestão Escolar

Sistema acadêmico para integração entre alunos, responsáveis,
professores e coordenação.

## Arquitetura

- Front-end: aplicação web
- Back-end: API REST
- Banco de dados: PostgreSQL
- Inteligência Artificial: análise de desempenho e risco

## Estrutura

frontend -> interface do usuário
backend -> regras de negócio e APIs
database -> scripts do banco
inteligencia-artificial -> modelos de análise
docs -> documentação do projeto
